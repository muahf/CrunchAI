# CrunchAI

Мобильное приложение для удалённого контроля питания домашнего питомца по звуку и фото. Не требует умных мисок и других приборов: достаточно двух смартфонов.

## Проблема

Владельцу важно знать, как питается питомец, пока его нет дома: насколько равномерно он ест и нет ли стресса во время еды. Существующие решения требуют покупки дополнительных устройств (умные кормушки, датчики веса, хабы).

## Целевая аудитория

Владельцы кошек и собак, которым важно здоровье питомца и которые хотят следить за ним удалённо.

## Как это работает

- Первый телефон остаётся дома рядом с миской. **Микрофон** улавливает звуки еды, **камера** подтверждает, кто у миски, и снимает состав корма.
- Данные синхронизируются через сервер (**сеть**) со вторым телефоном владельца.
- **Внешний источник данных — API OpenAI** (Vision, Whisper, LLM): анализ фото и звука, генерация рекомендаций.

## Ключевые функции

- Индекс спокойствия еды (темп, паузы, оценка от 1 до 10)
- Сканер состава корма по фото упаковки
- Определение, какой питомец у миски
- Умные уведомления о необычном поведении
- Недельный AI-отчёт в PDF для ветеринара
- Голосовые заметки (Whisper)
- Экономный режим: запись только по порогу громкости

## Аппаратные функции

Микрофон (основной датчик) - Анализ звуков еды 
Камера - Кто у миски, фото состава корма 
Сеть - Синхронизация двух телефонов через сервер
